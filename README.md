# Ahmed Bernous — Portfolio

Personal portfolio built with **Next.js 16**, **React 19**, **Tailwind CSS v4**, and the **Architect of Precision** design system (`DESIGN.md`).

## Run locally

Requires **Node.js 20+** (see `.nvmrc`).

```bash
nvm use
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

Site copy and structure live in `src/data/content.ts` — experience from your CV, projects and testimonials from [ahmedbernous.tech](https://ahmedbernous.tech).

## Build

```bash
npm run build
npm start
```
